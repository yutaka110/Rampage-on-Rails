# 区間カメラエディター

既存の Course Camera Shot と Sequencer を使って、画面で作った自由な構図を区間ごとに登録する。一人称・後方視点・アップは構図作りの出発点となるプリセットとして利用できる。

## 操作

1. Development または Debug でゲームを起動し、`Developer Tools` を ON にしてゲームを開始する。
2. コースを開き、下部ドックの `カメラ編集` を選ぶ。非表示の場合は Window メニューから開く。
3. `追加時の構図` と `区間の長さ` を設定し、`現在位置に区間を追加` で現在のコース位置に区間を追加する。既存のサンプル区間を選んでもよい。
4. 一覧で区間を選択し、右側の `詳細` で開始・終了距離と切替距離を決める。`初期構図` から一人称 / 後方視点 / アップを選ぶと、その初期構図に変更できる。
5. `画面上で構図を調整` を押す。区間内の確認位置でコースが停止し、自由に構図を作れる。確認位置が区間外なら区間中央へ移動する。
6. プレビュー内で右ドラッグすると視線を回転できる。右ボタンを押しながら WASD で前後左右、Q / E で下降・上昇、ホイールで前後へ移動する。Shift で高速、Ctrl で低速。`F` または `自機へ向ける` は自機へ視線を向ける。パネルの Left / Right / Up / Down / Near / Far でも微調整できる。
7. `画角` スライダーで画角を見ながら調整し、`自機を非表示にする` で自機と搭乗者の表示を決める。
8. `構図を反映` は現在の構図を選択区間に登録してその場所をプレビューする。`反映して再生` は登録後、区間の開始からすぐ再生する。登録した視点は `自由構図` になる。自由操作中は区間データを変更せず、`調整を破棄して戻す` で未登録の構図を取り消せる。
9. `区間を再生` は区間開始から再生し、区間終端で停止する。`開始位置 / 中央位置 / 終了位置`、`一時停止 / 再開`、`確認する距離`、`再生速度（0はコース設定）` でも確認できる。これらの再生・位置指定操作を行うと自由な構図作りを終了する。
10. `プレビューを終了して戻る` または `プレビュー終了` で元のコース位置に戻る。
11. コースのタブを選び Ctrl+S でファイルへ保存する。「構図を区間へ登録」と「コースのファイル保存」は別の操作。

区間の追加・削除・値の変更は、既存の Undo / Redo に対応する。Camera トラックでの移動や複製も利用できる。

## Map Editorでの3Dカメラ編集

1. Map Editor上部の `カメラ編集` を選ぶ。`コース編集` はレール、`敵・出現編集` は敵とWaveの配置操作をまとめたモード。地形や表示方式の設定は `表示の詳細設定（地形・表示更新）` にまとめている。
2. 右側の `編集する区間` で既存区間を選ぶか、3Dマップの `2点で区間を作成` を選び、レール上の開始位置・終了位置を順にクリックして作成する。逆順にクリックしても距離順に並べる。従来の `区間を追加` から長さを入力して作ることもできる。

   `区間を選択・調整` では、区間内のレールをクリックして選択できる。選択後は緑の丸が開始、赤の四角が終了。両端をレールに沿ってドラッグし、離すと範囲を確定する。ドラッグ中は仮の範囲を黄色で表示し、上部にも距離を表示する。範囲が見えないときは `選択区間を表示`、新しい場所を探すときは `レール全体を表示` を使う。
3. `構図を調整する` を押す。区間内の位置で停止して編集できる。Camera Editorの `3Dマップで編集` から開くこともできる。`撮影位置を表示` はカメラと画角の枠が見える位置までマップを寄せる。
4. 水色の `撮影位置` を左ドラッグして位置を動かす。このとき注視点は固定され、ゲーム映像も更新される。橙色の `注視点` を左ドラッグすると、カメラ位置を保ったまま視線を変更できる。
5. 構図調整中に撮影位置または注視点をクリックして操作対象を選ぶと、X（赤）・Y（緑）・Z（青）の軸が表示される。軸をドラッグするとその世界軸だけに沿って移動する。マーカー本体のドラッグは、マップの画面に平行な平面上を移動する。
6. マップ自体は右ドラッグで回転、中ドラッグで平行移動、ホイールでズームする。マップ上のF / ダブルクリックは、区間編集では選択区間、構図編集ではカメラ周辺へフォーカスする。2点指定中はダブルクリックによるフォーカスを無効にする。マップ操作は撮影カメラの位置・向きに影響しない。
7. 右側の `画角` と `自機を非表示にする` を調整する。ゲーム映像と上部の操作バーは設定欄のスクロールから独立して表示される。
8. 固定バーの `構図を反映` で区間に登録する。`反映して再生` は登録して区間開始から再生する。既存の構図の確認は `区間を再生`、`一時停止` / `再開`、`プレビュー終了` を使う。`再生中のカメラを追う` がONなら、マップが撮影位置を追従する。
9. 固定バーの `ファイルに保存` でコース全体を保存する。構図の反映とファイルへの保存は別の操作。コースタブを選んでCtrl+Sも利用できる。

### 3Dマップで区間の範囲を指定する操作

- `2点で区間を作成` → レール上を1回クリックして開始点を指定 → 別の位置をクリックして終了点を指定。最短は1m。作成には右側の `追加時の構図` を使用する。初期値は自由構図。
- `区間を選択・調整` → 対象区間のレールをクリック → 緑の開始点または赤の終了点をドラッグ。両端には距離を表示する。ハンドルが重なっても区別できるよう、開始はレールの少し上、終了は少し下に表示する。
- ドラッグ中はコースデータを変更せず、離したときに1件のUndo操作として確定する。開始と終了は交差せず、長さ1m以上を保つ。確定後は動かした端のゲーム映像を表示し、区間再生の終端も新しい範囲に更新する。
- Escで1点目だけの指定やドラッグを取り消す。フォーカス喪失・サイズ変更・対象区間の変更でもドラッグを取り消す。範囲指定の途中は保存や別の区間への切り替えを無効にする。
- 再生中は一時停止してから範囲を調整する。範囲指定モードを選ぶと再生中のプレビューを一時停止する。
- `構図を調整する` を押すと `構図を移動` に切り替わる。カメラ位置・注視点の編集とレール上の区間編集は入力を分けている。未反映の構図があるときは、反映または破棄してから区間編集に移る。
- 区間作成・範囲の変更は通常のUndo / Redoに対応し、ファイルへの保存は `ファイルに保存` で行う。新規作成をUndoした場合は、その区間の選択とプレビューも解除する。

### 変更状態と戻す操作

- `構図: 調整モード（変更なし）` は調整を開始しただけの状態。位置・向き・画角・自機表示を変更すると、橙色の `構図: 調整あり・未反映` になる。マップの回転やズームだけでは未反映にならない。
- `ファイル: 未保存の変更あり` は区間への登録やプリセット選択など、コースの変更がファイルに保存されていない状態。実際のコース文書の状態を表示する。自由構図の調整だけではファイルを変更しない。
- 未反映の構図があるときは、まず反映するか、右側の `調整を破棄して戻す` を使う。未反映のままの区間変更・モード変更・保存・通常の区間再生を防ぎ、調整を失わないようにしている。
- `通常追従に戻す` は選択区間の自由構図・自機非表示・従来の位置補正・画角補正・揺れ・参照プリセットを解除する。区間名・開始終了・ブレンド距離・優先度は保ち、Undo / Redoに対応する。他の重複区間のカメラ効果までは解除しない。
- `初期構図` の選択は区間データに直接反映される。自由ドラッグの場合は `構図を反映` まで一時的な調整となる。
- プレビュー中は上部に `プレビュー: 再生中` / `プレビュー: 一時停止` / `プレビュー: 区間終端で停止` を表示する。操作結果のメッセージとは別に、現在の再生状態から更新する。

水色の四角錐はゲーム描画と同じ画角・アスペクト比を使った視野の補助表示、青いレール部分は選択区間。地形は編集用の簡略表示なので、遮蔽物や最終的な見え方は隣のゲーム映像で確認する。

ドラッグ中のEsc、フォーカス喪失、ペインのサイズ変更などでは、そのドラッグを取り消す。再生中・読み取り専用状態ではカメラをドラッグできない。登録前のマップ操作はファイルやUndo履歴を変更せず、登録時に1つのUndo操作として反映する。

注視点の操作結果はレール基準の向き（Yaw / Pitch）として保存する。登録したカメラは走行に合わせて追従し、再読み込み後もその方向を再現する。マップ上の注視点までの距離は編集用の補助値。

## 詳細設定の日本語表記

マップからレール・制御点・敵・出現グループを選ぶと、右側の `詳細設定` → `詳細` に日本語の項目を表示する。レール制御点の位置・通路の半径・走行速度・接線、レール区間の開始距離・長さ、座標の基準・グリッド・移動ハンドルを調整できる。接線の選択肢は `自動` / `対称に連動` / `個別に調整`。接線や座標の基準、レールからのずれにマウスを重ねると説明が出る。

敵配置・出現条件・実行方法・区間の走行設定・カメラ詳細も日本語で表示する。保存されるアセットID・GUID・ユーザーが付けた名前はそのまま使用する。

## 視点

| View Mode | 初期設定 |
|---|---|
| Follow / Existing Shot | 既存の追従カメラとショットのオフセットを使用 |
| First Person | レール基準で高さ 5.8、前方 0.8。自機と搭乗者を非表示 |
| Rear View | 高さ 7、前方 14 から後ろを見る。車両は前進を継続 |
| Close Up | 高さ 6、後方 7、画角 50 度 |
| Custom Composition | 画面で自由に作って登録した構図。新規作成時の初期値は Close Up と同じ |

プリセット選択後も自由操作で構図を変更できる。数値で調整したい場合は `位置・向き・優先度の詳細` を開く。位置はレールの現在位置を基準に、X は左右、Y は高さ、Z は進行方向。左右の向きは 0 度が前、180 度が後ろ。画角は垂直画角。

自由な構図は確認位置のレール基準へ変換して保存するため、区間再生中もレールに沿って追従する。水平基準はレールの Up を使い、Custom では走行由来のロールを抑える。構図登録時は選択区間のシェイク・ロールオフセットを0にする。位置は各軸±1000、ピッチは±85度、画角は15〜110度が保存範囲で、範囲外なら登録を拒否して編集中の構図を残す。

区間の重複、ブレンド、地形への衝突回避は登録後の実走カメラにも適用される。登録直後のプレビューで最終的な構図を確認する。別の区間への選択変更、Undo、再生開始、プレビュー停止でも自由カメラの所有を解除する。

`Blend In Distance` と `Blend Out Distance` は区間内の距離で指定する。ブーストなどで速度が変わると、同じ距離を通る時間も変わるため、高速時の切り替えも確認する。明示的な視点は滑らかな重みで混ぜ、180 度の回転は設定した Yaw の側へ振り向く。

区間が重なる場合は `Priority` が高いものを優先し、同じ優先度なら既存のブレンド重みで選ぶ。選択したショットが常に最優先になるわけではないので、重複区間も確認する。

## ゲームとの接続

- プレビューと実プレイは同じ `RailCameraDirector` で視点を計算する。
- プレビュー停止中の位置指定ではカメラの過去の追従履歴をリセットし、指定位置の構図を確認する。再生中は履歴を保持する。
- 一人称などの明示的な視点は、通常の「車両全体を画面に収める」補正から除外する。共通の衝突・視認性・急な切り替えの判定は残す。
- タイトルからの移行や専用の登場演出は実プレイでは優先する。カメラ編集プレビューでは、それらの進行中の状態から独立して確認する。
- 明示的な視点では、ロック対象の距離を実際の照準カメラ方向で判定する。後方視点でも、後方に見える既存の敵を捕捉できる。
- 後方の敵編隊、攻撃パターン、戦闘終了条件は既存の敵・ウェーブ機能で別途配置する。後方視点を設定しただけでは敵は追加されない。
- エディターの Play / Simulate セッション中は専用プレビューを開始できない。編集プレビューと実プレイ確認を切り替えて利用する。

## データ互換性

`.course` の `camera_shot` 行に、視点の種類・位置・Yaw・Pitch・FOV・自機表示・優先度を追加して保存する。旧形式の行は従来の追従視点として読み込む。Sequencer は v2 のペイロードを使い、v1 も引き続き読める。

非有限値、無効なモード、範囲外の画角、不完全な視点データは反映しない。Play のスナップショットと変更検出にも視点設定を含める。

### Development版で編集画面が白くなる問題

300m付近での確認に加え、屋外へ切り替わる500m以降で再現条件を調べた。`SceneColor`の中間画像には地形と車両が描かれているのに、霧・大気を合成した編集画面では空のような白いグラデーションになっていた。

- 主原因はSRVの予約順序。`EngineContext`が深度SRVをスロット0に確保した後、`AppMain`が固定領域を予約し、ImGuiが同じスロット0にフォント画像を作っていた。深度を読むSunfall・DistanceFog・AOなどが別の画像を参照してしまう。固定領域の予約を`EngineContext`の最初のSRV確保より前へ移した。
- 編集ビューポートに合わせて色画像だけが縮小し、深度画像は起動時のウィンドウサイズのままだった。GPUの使用完了を待ち、深度画像も描画サイズに合わせて作り直すようにした。DSV・SRVのスロットは再利用する。
- 別の問題として、停止・プレビュー終了・テレポート時に編集用フリーカメラの古い位置が残る場合があった。編集用カメラへ入る際に現在のゲームカメラから位置と向きを引き継ぎ、継続中の手動移動は保持するようにした。

確認専用Developmentビルドで、屋外区間の通常表示、`Course Freeze`での停止、ウィンドウ最大化後も地形・車両・敵とUIの文字が正常に表示されることを実画面で確認した。編集カメラ、カメラ区間、Sunfallグラフ、HUD合成順序の回帰テスト4件も成功した。

調査時点では通常のDevelopment版と未保存のコースを維持した。その後、下記サンプル設定時に既存の編集を保存してゲームを終了し、通常のDevelopment実行ファイルも修正版へ再ビルドした。
